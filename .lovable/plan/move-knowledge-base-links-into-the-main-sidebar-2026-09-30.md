# Move Knowledge Base links into the main sidebar

## Goal
Remove the separate Knowledge Base sidebar and place User Docs, Settings, and View Online beneath Knowledge Base in the main navigation.

## Changes
- Expand Knowledge Base in the main sidebar while a Knowledge Base page is open.
- Add User Docs, Settings, and View Online as its three sub-links, with the current page highlighted.
- Keep the links accessible in the collapsed and mobile navigation states.
- Remove the redundant Knowledge Base sidebar from the article workspace and settings workspace.
- Preserve the existing article list/editor and all eight settings sections.

## Validation
- Check User Docs, Settings, and View Online navigation.
- Confirm article and settings layouts use the newly available width.
- Verify desktop, tablet, and phone layouts without horizontal overflow.
